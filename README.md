# Трекер гостей

Общий список гостей на 22–24 сентября. Страница открывается по ссылке **без регистрации и входа**:
все, кто откроет её, видят одни и те же данные и могут их править — правки сразу сохраняются на сервере.

## Как это устроено

| Что | Где |
|---|---|
| Сайт (HTML + CSS + JS, без сборки) | папка `public/`, публикуется на GitHub Pages |
| Данные (гости + шаблон приглашения) | Cloud Firestore, обращение напрямую по REST |
| Публикация | GitHub Actions — `.github/workflows/deploy.yml` |

Синхронизация: страница опрашивает базу раз в 5 секунд и при возврате на вкладку,
поэтому чужие правки появляются сами, перезагружать ничего не нужно.

## Как обновить сайт

Любое изменение в `public/` попадает на сайт автоматически:

```bash
git add -A
git commit -m "что поменяли"
git push origin main
```

Через ~1 минуту GitHub Actions пересоберёт и опубликует сайт.
Ход публикации виден во вкладке **Actions** репозитория.
Правка через веб-интерфейс GitHub (кнопка ✏️ на файле → Commit) работает точно так же.

## Настройка базы данных

Подключение задаётся в одном файле — `public/config.js`:

```js
window.GUESTS_CONFIG = {
  projectId: "…",   // ID проекта Firebase
  apiKey: "…"       // Web API Key (публичный, не секрет)
};
```

Как получить эти значения:

1. [console.firebase.google.com](https://console.firebase.google.com/) → **Add project** (Google Analytics можно выключить).
2. **Build → Firestore Database → Create database**, режим **Production**, регион `eur3` или `europe-west3`.
3. Вкладка **Rules** → вставить содержимое `firestore.rules` из этого репозитория → **Publish**.
4. ⚙️ **Project settings → General** → внизу **Your apps → Web (`</>`)** → скопировать `projectId` и `apiKey`.
5. Вписать их в `public/config.js` и запушить.

Правила намеренно открытые: сайтом пользуются несколько человек без логина.
Кто знает ссылку — может править список; данные не содержат ничего чувствительного.
Если понадобится закрыть доступ — поменяйте правила в Firebase Console на `if false`,
сайт сразу перестанет пускать к данным.

## Стартовые данные

При самом первом открытии, если база пустая, в неё автоматически записываются
46 гостей и стандартный шаблон приглашения. Дальше всё редактируется через интерфейс.
Повторно засев не срабатывает — даже если страницу одновременно открыли с двух устройств.

## Возможности

- Поля: имя, дата, статус (✅ / ❓ / ❌), ответственный, отправлено, заметки — всё правится прямо в таблице.
- Пары и «+1» подсвечены общим цветом (цвет назначается автоматически по `groupId`).
- Сводка: всего гостей, всего подтвердивших и подтверждения по каждой дате.
- Фильтр по датам, поиск по имени, добавление и удаление гостей.
- Общий шаблон приглашения с подстановками `{Имя}`, `{Дата}` (→ «22 сентября») и `{ДатаЦифрами}` (→ «22.09»),
  под таблицей — готовый текст для каждого гостя с кнопкой «Копировать».
